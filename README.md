# Copycat! — Style Transfer with Imagen 3.0

> Reimagine any image in a brand-new visual style — powered by Google Imagen 3.0.

Copycat! is a fast, elegant web app for artistic style transfer.

## ✨ Features
- 🎨 Imagen 3.0 style transfer
- ⚡ Instant feedback — Vite hot-reload
- 📱 Responsive UI
- 🧩 Type-safe — React + TypeScript
- 🚀 Deploy-ready

## 🚀 Getting started
bash
npm install
npm run dev


## ☁️ Deploy
Static dist/ — Render (build: npm install && npm run build, publish dist), Netlify, Vercel.
